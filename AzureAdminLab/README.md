# Azure Administrator Lab

Hands-on Azure administration lab built in a real Azure tenant alongside my AZ-104 (Microsoft Azure Administrator) certification prep. Structured around the official AZ-104 exam skill areas — identity and governance, storage, compute, networking, and monitoring — each phase below documents real work as I complete it, not just course notes.
